# Attiq Ur Rehman — Research Portfolio

Personal academic website for Attiq Ur Rehman, focused on wireless communications, 6G TN/NTN integration, satellite communications, AI for networks, and ISAC.

## Deploy on GitHub Pages

1. Create a public repository named `Attiq109.github.io`.
2. Upload **the contents of this folder** to the repository root (not the outer folder itself).
3. Commit to the `main` branch.
4. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / root**.
5. The site will be published at your GitHub Pages address after deployment completes.
